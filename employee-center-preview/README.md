# LINE 打卡系統 V2 — 四格介面安全預覽（2026-10-28）

## 網址與安全界線

- 預覽網址：https://line-punch.github.io/attendance-v2-test/employee-center-preview/
- 本資料夾僅展示介面，和 `main/index.html` 的 V2 TEST001 GPS 實際隔離打卡**不同**。
- HTML 的 CSP 禁用網路連線（`connect-src 'none'`）及表單提交（`form-action 'none'`）。
- JavaScript 不含 LIFF、LINE Token、Apps Script URL、GPS 或真正資料。所有打卡、補卡及請假按鈕只回傳「預覽不寫入」訊息；不觸發主管通知。
- 表格顯示**明確標註的假資料**，不代表任何員工的打卡或申請結果。
- 更換本預覽頁不會修改正式倉庫 `line-punch/line-punch`、正式後端、正式 Google Sheet 或原有 `attendance-v2-test/main/index.html` GPS 測試頁。

## 正式 LINE 四格選單的目標規格

目前正式 LINE 圖文選單仍維持四格，預計第四格「出勤紀錄」改名「人資查詢」，但目前未修改 LINE OA。

| 四格入口 | 對應介面 | 後端未來資料來源 |
| --- | --- | --- |
| 我要打卡 | 上班、下班；**當月**每個日期一列，原始時間精確到秒；空缺不以核准補卡時間補上 | `打卡紀錄` A:K |
| 忘記打卡 | 目前只可補今天/昨天，補上班或下班；顯示補卡日期、類型、補登時間、審核狀態 | `補打卡申請` A:M |
| 人資查詢 | **只讀**，當月與前兩個月：出勤、請假、補卡、本人基本資料 | `打卡紀錄` + `補打卡申請` + `請假申請` + `員工資料` |
| 我要請假 | 單日、連續多日、指定時段；保留事／病／特休／公／婚／喪及申請狀態 | `請假申請` A:L |

重點：
- 原本打卡只有「上班」「下班」兩類；**沒有午休開始或午休結束**。
- 查詢日期跨月/跨年時，月份選單只列本月及前兩個月。
- 跨週末、法定假日與補班日，必須由正式後端套用公司工作日曆計算，不依預覽中的曆日推算請假時數。
- 仍待設計與測試：權限驗證、雙重提交保護、主管審核、防重複寫入、出勤封存、NFC NTAG 424 DNA AES/SUN/SDM、iPhone/Android 對接。
- 歷史封存表 `打卡紀錄_歷史` A:K 與現行 `打卡紀錄` 相同；目前正式 Apps Script 沒有自動封存程式/觸發條件。先測試、核對備份，再考慮每月結算後封存。
- 主管通知與審核結果通知維持原需求，但網頁打卡成功提示不需 LINE Push。
