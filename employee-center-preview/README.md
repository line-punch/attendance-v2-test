# 員工 LINE 人資中心 V2 — 七功能介面預覽（2026-10-22）

## 已發布的純介面預覽

GitHub Pages： https://line-punch.github.io/attendance-v2-test/employee-center-preview/

此路徑與既有打卡測試 LIFF 不同，不取用 LINE SDK、Google Apps Script、GPS 或正式試算表。GitHub Pages workflow 已顯示部署成功；需由使用者用手機確認實際版面。

### 已做好的七個入口

| 按鈕 | 在預覽中的內容 | 上線後資料來源 |
| --- | --- | --- |
| 正常打卡 | 保留原上／下班按鈕、定位狀態、當日紀錄及結果不明查詢 | V2 verified clock / todayAttendance |
| 補打卡 | 保留日期、類型、時間、原因、申請紀錄 | 原 13 欄補打卡申請 + V2 安全寫入 |
| 出勤查詢 | 保留 YYYYMM 最近三個月查詢 | 現行打卡與封存年庫 |
| 請假申請 | 保留事／病／特休／公／婚／喪六假別、全天／時數及紀錄 | 原 12 欄請假申請 + V2 安全寫入 |
| 特休查詢 | 顯示「建置中」，未顯示虛構時數 | 到職週年制特休台帳及異動 |
| 薪資查詢 | 顯示「建置中」，不顯示未核定薪資 | 管理者已核定發布的本人薪資 |
| 歷史紀錄 | 顯示「建置中」，不查未建年度庫 | 分年度出勤、請假、補卡、特休歷史 |

原本四項功能的完整表單 HTML 在整合分支保留；未完成串接的寫入一律不送出。正式員工打卡網站及 V2 已實測成功的入口皆不變。

### 將來的權限功能

主管審核入口不預設顯示給所有員工；經後端 LINE 身分查詢原 `審核通知名單` E 欄有審核權時才展示。C/D 只收通知不等於有核准權限。

### 安全保證與限制

- `employee-center-preview/app.js` 不呼叫 API、LINE 登入、GPS 或試算表。
- 打卡、請假、補打卡按鈕在預覽只回覆說明，沒有實際寫入。
- 特休、薪資與歷史資料尚未完成後端串接，不虛構數字。
- 任何員工不能把純預覽頁當作真實打卡入口。
- 存量回歸測試：`employee-center-preview/preview.test.js` 11／11 通過；七功能隔離整合頁（`Legacy4PageReuse.test.js`）15／15 通過。
- 完整串接、角色權限、薪資安全及跨月歷史資料驗證完成後，才可討論正式切換。
