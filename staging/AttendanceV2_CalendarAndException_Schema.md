# V2 打卡／人資工作日曆：精簡成兩張工作表（2026-10-29）

> **本文件取代前一版四表草案。** 現在實際打卡以一間公司為主；原程式雖預留兩間公司／兩個打卡地點，但目前不需要為未啟用的公司建立審核流程。本文件僅在 V2 隔離測試分支修訂，不建立或修改正式 Google Sheet、Apps Script、LINE 選單與 Excel。

## 一、精簡結論

**保留：**
1. 「公司工作日曆」：預設週一至週五為上班日、週六週日休息；只新增「國定假日、補班、公司另行休假」等例外日期。可在表格旁放「當年度資料已核對」的設定與版本，不獨立設「工作日曆月份核定」分頁。年度資料核對一次即可；有異動時記錄更改與確認時間，不必每月重新簽核。
2. 「特殊出勤事件」：一筆記錄颱風等停班事件，同時處理適用公司、工作地點、全員／特定員工、排除員工、停班時段、是否依公司政策照薪、佐證及核定人。個別適用員工列在該事件紀錄的欄位內，不獨立設「特殊出勤個別認定」分頁。

**取消獨立表：**「工作日曆月份核定」、「特殊出勤個別認定」。

未來若開始讓第二間公司實際打卡，再在相同表格增加公司／地點欄位的適用值即可；不提前要求逐月核定或每人一筆。

## 二、表格草案（**只規劃，尚未建立**）

### A. 公司工作日曆（例外日期清單）

平日預設工作，不需逐日建檔。人資每年核對當年度休假表後，於**同張工作表的設定區**記錄：「適用年度、核對完成、核對日期、核對人、版本」。未核對的年度不得當成正式請假核准依據。

| 欄 | 欄名 | 說明 |
| --- | --- | --- |
| A | 日期 | YYYY/MM/DD |
| B | 公司 | 目前只有實際使用的一間；保留另一間擴充 |
| C | 適用打卡地點 | 空白代表目前所有地點；有例外才填地點 |
| D | 日別 | 上班／休假 |
| E | 原因 | 國定假日、政府補班、公司另行休假、其他 |
| F | 核對依據 | 公司行事曆／官方公告 |
| G | 備註 | 調整原因與適用說明 |
| H | 更新及確認紀錄 | 由程式保留可追溯的操作資訊 |

- 日期衝突、不合法日別、年度尚未核對時，不能偷偷回退到「週一至週五上班」就放行正式假單。
- 日期跨週末、國定休假或公司休假，應顯示哪些日期不合規，要求拆單；核定的補班週六則可申請。
- **颱風停班通常不直接改成一般休假日**；優先由下方「特殊出勤事件」處理，避免影響原有假單與工時紀錄。

### B. 特殊出勤事件（含個別例外）

| 欄 | 欄名 | 說明 |
| --- | --- | --- |
| A | 事件單號 | 唯一值 |
| B | 日期 | 停班日期 |
| C | 時段 | 全日或開始／結束時間 |
| D | 事件類型 | 颱風停班、天然災害、其他經核定的出勤例外 |
| E | 適用範圍 | 全公司／指定打卡地點／指定員工 |
| F | 地點代碼 | 選「指定打卡地點」時填寫 |
| G | 指定員工 ID | 少數員工因居住地、通勤等情況個別適用時填寫；僅內部表儲存 |
| H | 排除員工 ID | 全公司／整個地點適用但有例外時才填寫 |
| I | 給薪處理 | 依公司政策照薪／另行核對 |
| J | 公告或佐證 | 官方公告網址／內部核定備註 |
| K | 審核狀態 | 待確認／已確認／取消 |
| L | 確認人／時間 | 人資留存操作紀錄 |
| M | 備註 | 部分停班、已請假衝突、需另外處理的狀況 |

這是**事件層級**資料，非每位員工每日一列。公司全面停班通常一筆；如只有特定員工適用，E 選「指定員工」並填 ID。若適用範圍不清、員工有爭議、事件重疊，保留「待人資確認」，不能自動寫成曠職或扣薪。

### 例子（全部為虛構測試資料）

- 整間公司停班：事件一筆，E=全公司，I=照薪。
- 只有某個工作地點停班：事件一筆，E=指定打卡地點，F=該地點代碼。
- 公司所在地正常上班，某員工居住地停班且依法適用：事件一筆，E=指定員工，G=該員工 ID。
- 颱風只停班半日：C 填具體時段；當日其餘時段的出勤仍需核對，不因有停班事件就認定全日已完成出勤。
- 有員工停班日仍實際出勤：保留真實上、下班打卡與工作時數，額外給付或工資計算交人資核對。
- 已核准特休與天災停班重疊：不得自動撤銷特休或覆寫原假單，交人資處理。

## 三、對現有系統的影響

- 正式員工 LINE 四格**不需要新增颱風假、例外申請或員工查核按鈕**。
- `打卡紀錄` A:K、`打卡紀錄_歷史` A:K、`補打卡申請` A:M、`請假申請` A:L 完全不動。
- 遇人資已確認適用的天災停班，當日原始打卡可以是空白，但出勤判定不是曠職、全勤不扣；依公司照薪政策計薪。**實際工作時間仍為零，絕不能假造打卡**。
- 出勤與薪資 Excel 的對接須能分開「實際工作時數」、「受保護未出勤時數」、「公司照薪時數」，避免把颱風停班當成加班。
- 員工工作地、居住地與通勤必經地可能有不同停班情形，不能單憑公司所在縣市自動替所有員工下結論。
- 工作日曆例外仍需每年核對一次，且有新增政府公告或公司政策異動時需補充；不是放著完全不用管理。
